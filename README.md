# IG Account Processor

Android app (React Native + Expo + TypeScript) for importing Instagram usernames from XLSX/CSV/TXT, storing them locally in SQLite, and manually processing profiles one by one.

The app never follows, unfollows, messages, scrapes, or automates Instagram. It only opens profile links; the user performs every action manually.

Work in progress; built in phases. A full README follows in the final phase.
